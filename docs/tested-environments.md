# Tested Environments

OASYS Public Core v1 has currently been empirically tested using ChatGPT.

## Current Tested Environment

- **ChatGPT** — All formal Public Core v1 validation was executed using ChatGPT.
- **ChatGPT** — All current Scenario 1–5 recorded portfolio evidence was executed using ChatGPT.

## Current Boundary

Equivalent OASYS behavior has not yet been demonstrated on other LLM platforms.

OASYS is intended for LLM-assisted execution generally, but that architectural intent must not be interpreted as empirical proof of equivalent cross-platform behavior.

## Future Updates

Additional environments will be added to this page only after applicable testing has actually been performed.

Any later environment entry must identify the applicable test or evidence basis sufficiently to support the claim.
